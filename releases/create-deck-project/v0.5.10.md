# create-deckio v0.5.10

Newly scaffolded decks now use `@deckio/deck-engine` **`^1.22.2`**, including
the hardened PDF and PowerPoint export capture.

## What changed

- Update the bundled engine range from `^1.22.0` to `^1.22.2` so published
  scaffolds receive the badge, colour, gradient, asset-readiness and animation
  capture fixes by default.
- Preserve local-workspace `file:` references to the engine source.
